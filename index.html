void loop() {
  bool motion = digitalRead(PIR_PIN);  // GPIO 26
  bool helmet = digitalRead(IR_PIN);   // GPIO 27
  showStatus(motion, helmet);          // OLED
  if (motion && !helmet) {
    digitalWrite(BUZZER_PIN, HIGH);    // GPIO 25
  } else {
    digitalWrite(BUZZER_PIN, LOW);
  }
  delay(100);
}

How it works

  1. The 9V battery feeds the LM2596, set to 5V, which powers the ESP32 VIN pin and the 5V rail.
  2. A person enters and the PIR sensor raises GPIO 26.
  3. The IR sensor raises GPIO 27 when it detects the helmet.
  4. The OLED shows Helmet and Motion status.
  5. If motion is seen and the helmet is missing, the buzzer on GPIO 25 sounds.

Important notes

  • Use the 5V buck converter. Never connect 9V directly to the ESP32.
  • The ESP32 runs 3.3V logic, but the PIR, IR and OLED modules use 5V.
  • If the IR output is 5V, use a 10kΩ + 20kΩ divider to get 3.3V on GPIO 27.
  • Battery, buck converter, ESP32, sensors, display and buzzer must share ground.
  • Adjust the PIR and IR potentiometers for the right detection range.
